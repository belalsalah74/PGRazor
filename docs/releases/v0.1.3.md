# PGRazor v0.1.3

## Changes

- **GPX routes:** Import GPX waypoints, routes, and tracks. Save and export routes from the world map, or choose an imported or saved route in Autowalk. Routes support looping.
- **Route safeguards:** Tapping the in-game map during a planned route or Autowalk now asks before stopping it. Cancelling keeps you walking, and confirming consumes the accidental tap without moving you to that spot.
- **Map controls:** Return the world map to your current location and clear a route directly from the route controls.
- **Dynamax battles:** Recover attack controls when battle setup callbacks are missed so automatic quick and charged attacks can start.
- **Throw variation:** Nice, Great, and Excellent throws now vary within their selected circle-size range while keeping one consistent value throughout each throw.
- **Location stability:** Route location updates through provider listeners to address Android runtime crashes without replacing the game's native location-update method.
- **Maintenance and reliability:** Refactor the runtime, settings, and map into smaller modules; order background settings writes; fix map tile request tracking; and improve cleanup of catch animations and IV labels.
- **Project website:** Add a dark/light showcase with screenshots, features, and download links at https://jpitty03.github.io/PGRazor/.

## Installation

Download **PGRazor.apk** and install it over your existing PGRazor installation to preserve settings. You can also export a settings backup before updating.

## Validation

Throw variation and Dynamax attacks were confirmed working during device testing. GPX parsing and round-trip export, route safeguards, location delivery, and runtime modules have automated checks. GitHub Actions runs the device-free checks and builds the release APK. End-to-end testing of every GPX workflow and device combination remains limited.
