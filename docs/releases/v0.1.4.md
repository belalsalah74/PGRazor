# PGRazor v0.1.4

## Changes

- **One APK for Android and MuMu:** The app automatically selects the appropriate runtime. Install the same PGRazor.apk on your ARM64 phone or MuMu.
- **MuMu gameplay hooks:** Connect Android controls to the translated ARM game runtime, enabling the existing Quick Catch, VGP, berry, transfer, IV, and other native features.
- **GPS permission fixes:** Fix early permission initialization so location spoofing can start when the app's Android location permission is denied.
- **Runtime reliability:** Validate translated ARM executable segments, stop native feature activity when settings snapshots become stale, and adapt empty gift-dialog callbacks for MuMu. Phones retain their existing ARM runtime path.

## Installation

Download **PGRazor.apk** and install it over your existing PGRazor installation to preserve settings. No separate emulator APK or root service is required.

## Validation

The same candidate APK reached the game map on an Android phone and MuMu with app location permission denied. Native gameplay hooks initialized on both, automated checks passed, and preliminary gameplay testing was reported successful on both. Broader emulator and gameplay coverage remains limited.
