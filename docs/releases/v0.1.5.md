# PGRazor v0.1.5

## Changes

- **Always Hit:** A new option under Settings → Throws converts missed ball collisions into hits. Pokémon can still break free or flee. Works with manual throws on Android and MuMu.
- **LivePokeMap autofill:** Keep the login form open when using a password manager and provide username/password autofill hints.
- **Simpler teleport:** Paste coordinates into a single field in the quick menu, with or without a space after the comma.

## Installation

Download **PGRazor.apk** and install it over your existing PGRazor installation to preserve settings. The same APK supports ARM64 Android phones and MuMu.

## Validation

Always Hit was tested with off-target throws in MuMu, including successful catches and a break-free followed by a successful retry. The same candidate APK was installed on an Android phone and reported working. Automated checks cover collision handling, duplicate prevention, setting controls, and existing gameplay hooks.
